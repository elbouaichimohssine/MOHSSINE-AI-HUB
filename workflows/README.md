# Automation Workflows

A collection of no-code workflow notes and experiments.

## Workflow documentation template

- **Purpose:** The task to automate
- **Trigger:** What starts the workflow?
- **Steps:** What happens, in order?
- **Services:** Which apps or platforms are involved?
- **Cost:** Free-tier limits or paid requirements
- **Reliability:** What happens when a step fails?
- **Privacy:** What data is processed and where?

## Planned topics

- Organizing content-production tasks
- Preparing digital-product publishing checklists
- Connecting forms, spreadsheets, and notifications

Only workflows that have been tested should be described as working.
