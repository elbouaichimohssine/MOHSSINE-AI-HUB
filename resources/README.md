# Resources & Tools

A living list of tools and references used in projects.

## Tool notes

When adding a tool, include:

- What it is useful for
- Whether a free plan is available
- Important usage limits
- A link to its official website
- Which project uses it

## Current toolkit

- **GitHub** — project files and documentation
- **Canva** — visual design and document layout
- **AI assistants** — research, drafting, ideation, and learning support

This list reflects tools being explored; it is not an endorsement or a claim of advanced expertise.
