# AI Experiments & Projects

This folder is for small, practical projects built while learning AI tools.

## Project documentation template

For each project, record:

1. **Goal** — What problem does it solve?
2. **Tools** — Which AI tools, platforms, or languages are used?
3. **Steps** — How can someone reproduce it?
4. **Result** — What works, with examples or screenshots where useful?
5. **Limitations** — What still needs improvement?

## Planned first experiments

- AI-assisted research and content planning
- Visual asset creation for educational products
- Simple tools that support everyday productivity

*Experiments will be added as they are completed and tested.*
