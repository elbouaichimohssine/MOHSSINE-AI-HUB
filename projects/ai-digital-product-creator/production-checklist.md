# Production Checklist — English Learning Workbook

## 1. Audit existing work
- [ ] Find the latest source file in Canva.
- [ ] Find all exported PDF versions (A4 and any other format).
- [ ] Confirm which edition is currently listed on Gumroad.
- [ ] Record the current title, page count, price, and delivered files.
- [ ] Compare the existing edition with the proposed 60-page plan.
- [ ] Choose: update existing edition or create a separate edition.

## 2. Content
- [ ] Confirm learning objectives for each section.
- [ ] Write separate difficulty levels for ages 6–7 and 8–10.
- [ ] Use natural, age-appropriate English.
- [ ] Keep instructions short and unambiguous.
- [ ] Check every answer key against its activity.
- [ ] Review spelling, grammar, punctuation, and consistency.
- [ ] Remove duplicated or overly repetitive activities.

## 3. Canva design
- [ ] Set document to A4.
- [ ] Use a printer-friendly white background.
- [ ] Apply a consistent pastel palette.
- [ ] Use readable fonts and strong text contrast.
- [ ] Keep margins and page numbering consistent.
- [ ] Use original or properly licensed illustrations only.
- [ ] Check that no text or activity is cut off.

## 4. Export and inspection
- [ ] Export as PDF Print or the most suitable high-quality PDF option.
- [ ] Confirm the PDF opens correctly.
- [ ] Check total page count and page order.
- [ ] Inspect every page, not only the cover.
- [ ] Test print representative pages in grayscale and colour.
- [ ] Verify that answer spaces and small text remain usable.

## 5. Gumroad readiness
- [ ] Product title matches the actual file.
- [ ] Description accurately states age range, language, format, and contents.
- [ ] Preview images show real pages from the final workbook.
- [ ] Price and files are checked before publishing.
- [ ] Downloaded customer files match the final reviewed export.
- [ ] Test the purchase/download flow where possible.
