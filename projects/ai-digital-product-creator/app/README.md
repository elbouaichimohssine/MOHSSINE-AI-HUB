# AI Digital Product Creator — Web App

This folder contains the first static MVP of the MOHSSINE AI HUB product-planning app.

## Run locally
Open `index.html` in a modern browser. No build step, package installation, or API key is required.

## MVP features
- Product name, type, language, audience, page count and level inputs
- Browser-side product plan generation
- Copy plan to clipboard
- Download plan as a plain-text file
- Responsive blue-and-white interface

## Current limitations
- No AI model is connected yet; the plan is assembled from a local template.
- No Canva, Gumroad, database, login, or cloud saving integration.
- Generated plans are not saved after the page is closed.
