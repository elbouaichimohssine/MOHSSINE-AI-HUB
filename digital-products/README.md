# Digital Products

This folder documents digital products created or developed as learning projects.

## Product categories

- Educational workbooks
- Social media and branding templates
- Practical guides and checklists

## Before publishing

- Check spelling, layout, and page consistency
- Confirm page size and export quality
- Verify that all fonts and visual assets are licensed for the intended use
- Test the download file
- Write a clear product description and state exactly what buyers receive
